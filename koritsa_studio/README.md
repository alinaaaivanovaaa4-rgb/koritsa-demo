# Сайт Корицы с подбором по вкусу

Рабочая версия сайта с главной страницей, полным меню и интерактивным подбором. Опрос использует существующие 64 позиции, предлагает до трёх подходящих вариантов и позволяет сравнить две позиции по цене и составу.

## Просмотр

План показа заказчикам через GitHub Pages и команды публикации: [DEPLOYMENT.md](../DEPLOYMENT.md). Подготовка проверенного артефакта: `python3 tools/prepare_pages.py` из корня проекта.

```sh
python3 -m http.server 4282 --bind 127.0.0.1 --directory koritsa_studio
```

- Главная: <http://127.0.0.1:4282/>
- Меню: <http://127.0.0.1:4282/menu.html>
- Подбор: <http://127.0.0.1:4282/choose.html>

## Изменение меню и рекомендаций

`data.json` содержит названия, цены, вес, состав, категории и привязки фотографий. `recommendations.json` содержит только вопросы, вкусовые признаки, краткие описания и порядок первых рекомендаций. После изменения данных запустить из корня проекта:

```sh
python3 tools/build_studio.py
```

Сборка обновляет все три страницы. Данные подбора встроены в `choose.html`, поэтому в браузере нет отдельного запроса за меню. Цена и полный состав подбора берутся из той же позиции, что и в обычном меню. При добавлении позиции добавить её профиль в `recommendations.json`; сборка проверит идентификаторы, категории и признаки. При изменении рецептуры пересмотреть соответствующие признаки и короткое описание.

`picker-core.js` определяет доступные вопросы и точные совпадения. Вкус и основные ингредиенты фильтруют результат; вариант «Любой» сохраняет весь подходящий набор. Вопросы заканчиваются раньше, если продолжение не сужает выбор. Сортировка учитывает `featured` внутри выбранного формата, затем исходный порядок меню. Кнопка «Ещё идеи» позволяет увидеть оставшиеся позиции.

`picker.js` управляет страницей, адресом и сравнением. Ответы сохраняются в параметрах `moment`, `direction` и `flavour`; ссылки можно открыть повторно. При изменении более раннего ответа следующие ответы и сравнение очищаются. Сравнение сохраняется при просмотре следующих рекомендаций в текущей подборке. Внешние системы аналитики или отправки заказов не подключены.

`picker.css` содержит стили опроса и результатов. Фотография общего стола используется для атмосферы на большом экране; на телефоне она скрыта. Фотографии в результатах привязаны только к подтверждённым блюдам. Для позиций без снимков используется фирменная графика.

## Проверки

Отчёты и снимки первой версии: `.impeccable/review/menu-picker/` в корне проекта. `engine-report.json` отражает проверку всех конечных веток. `browser-check.js` проверяет интерфейс, сравнение, переходы в меню, историю браузера, клавиатуру и размеры экрана; `browser-report.txt` содержит результат прохода.

Правила подбора не определяют наличие по адресам, время подачи завтраков, аллергенную безопасность или пищевую ценность. Эти свойства требуют данных от кофейни. План пилота и развития находится в `MENU_PICKER_PLAN.md` в корне проекта.
